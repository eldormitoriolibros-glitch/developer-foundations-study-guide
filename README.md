# Developer Foundations Study Guide

Personal study notes for the **Claude Certified Developer – Foundations** exam (CCDV-F).

| File | What it is |
| --- | --- |
| `index.html` | The full interactive guide: exam facts and blueprint, a timed 53-item mock exam, readiness by domain, the study toolkit (diagrams, summary tables, spaced-repetition drill), hands-on labs, and summaries of the five prep modules plus Building with the Claude API, Introduction to MCP and MCP: Advanced Topics. |
| `Developer-Foundations-Study-Guide.pdf` | Offline copy of the same content (77 A4 pages), ending with all 108 practice questions and their answers. |

## Opening it

- **Online:** https://eldormitoriolibros-glitch.github.io/developer-foundations-study-guide/
- **PDF:** click `Developer-Foundations-Study-Guide.pdf` above; it opens in GitHub's viewer.
- **Offline:** download the repo (**Code → Download ZIP**) and open `index.html` in a browser.

Quiz answers, drill progress and mock results are saved only in the browser you use.
